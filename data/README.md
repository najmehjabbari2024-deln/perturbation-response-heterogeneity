# Dataset

**File:** `AdamsonWeissman2016_GSM2406675_10X001.h5ad`

This dataset is from the scPerturb harmonized collection (Peidli et al., 2022) and originates from Adamson et al. (2016, Cell).

The file contains a K562 pilot experiment involving non-essential transcription factors and cell-cycle regulators. It represents a pilot experiment within the Adamson study rather than the main unfolded-protein-response screen.
